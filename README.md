# AI 개발 인계실

2~4명 개발팀이 OneDev, Codex, Claude로 Next.js 기반 AI 솔루션을 개발할 때 변경 맥락과 검증 근거를 공유하는 도구입니다.

현재 단계는 **상세 설계 초안 작성**이며 애플리케이션은 구현하지 않았습니다.

- [상세 설계서](docs/design.md): 제품 범위, 사용자 흐름, 데이터 모델, 수집·분석 구조, API, 검증 및 단계별 구현 범위
- [설계 결정 기록](docs/decisions.md): 합의된 방향, 제안한 기술 결정, 구현 전 확인 사항

## 초기 범위

OneDev 변경 수집 → 작업 카드 연결 → AI 인수인계 초안 → 코드·테스트 근거 대조 → 팀 공유 → 다음 AI 작업에 맥락 제공.

초기 제안 구성은 Next.js, PostgreSQL, 별도 분석 워커이며 그래프 탐색 UI는 React Flow를 사용합니다. 외부 원격 저장소와 실제 OneDev 연결은 아직 설정하지 않았습니다.
