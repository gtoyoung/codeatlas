# 설계 결정 기록

## 사용자 확정 내용

- 2~4명 팀, OneDev Git 관리, Codex·Claude 사용, Next.js 기반 AI 솔루션.
- 개인 코드 이해와 팀원의 변경 이해를 함께 지원한다.
- Git 커밋과 로컬 소스만 분석 입력으로 사용한다.
- OneDev API·PR·리뷰 연동, Claude Code 인계 파일, 테스트 실행·배포 기록 수집은 제외한다.
- 상세 설계를 먼저 작성하며 대화 응답은 짧게 유지한다.

## 2026-09-13: v0.2 범위 정정

v0.1의 PR·작업 카드·외부 인계·검증 결과 중심 구조를 Git 변경·소스 스냅샷 중심으로 대체한다. 과거 설계는 Git 이력에 보존하며 현재 구현 기준은 v0.2다. 제외한 연동은 향후 예정 기능으로도 유지하지 않는다.

## 설계 제안

| 결정 | 이유 | 재검토 조건 |
|---|---|---|
| 로컬 분석을 첫 버전으로 | 기존 clone과 미커밋 소스를 직접 읽음 | 팀 공통 화면 필요 시 서버 clone 모드 추가 |
| 커밋·소스 스냅샷을 중심 단위로 | 별도 업무 입력 없이 근거 확보 | 원칙 유지 |
| PostgreSQL에 그래프 저장 | 초기 운영 구성 단순화 | 실제 그래프 질의 부담 증가 |
| React Flow 단계적 추가 | 변경 이해 흐름부터 검증 | 지도 필요성이 파일럿에서 확인될 때 |
| 별도 워커 | 웹 요청과 긴 분석 분리 | 실행 환경 제약 |
| LLM 근거·버전·추정 구분 | 코드만으로 알 수 없는 사실의 오인 방지 | 원칙 유지 |
| 확인 제안과 실행 검증 구분 | 테스트 소스는 실행 결과가 아님 | 원칙 유지 |

## 구현 전 확인

로컬 저장소 경로·OS·기준 브랜치, 실제 소스 구성, LLM API·전송 정책·예산을 확인한다. OneDev 업무 API·AI 인계 자동화·테스트/배포 시스템 연결은 요구하지 않는다.
